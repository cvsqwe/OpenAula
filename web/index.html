Remap

Bind keys to other keys, or to multi-step macros. Applied system-wide by openaula-remapd.

Remap engine

Grabs the F75's keystrokes system-wide so the bindings work in every app. It stays completely inert - never grabbing the keyboard - until it's enabled here and at least one binding is set.

openaula-remapd isn't installed on this machine. Run ./install.sh from the project root (see the README), then reload this page.

Settings

Background daemon and LED calibration.

Background daemon

openaula-daemon keeps the backlight running even when this page is closed. openaula-webd (this page's server) never touches the keyboard directly - it writes the config file the daemon reads and wakes it up instantly.

Calibration

Walks through every LED one at a time - watch the physical keyboard and click whichever key lights up. Starting over replaces the existing mapping, so this is also how to fix a calibration that went wrong.
