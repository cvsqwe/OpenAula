Remap Engine

openaula-remapd grabs the F75's keystrokes system-wide to apply the bindings below to every app, not just this page. It stays completely inert - never grabbing the keyboard - until it's enabled here and at least one binding is set.

openaula-remapd isn't installed on this machine. Run ./install.sh from the project root (see the README), then reload this page.

Settings

Background daemon and calibration status.

Background Daemon

openaula-daemon keeps the backlight running even when this page is closed. openaula-webd (this bridge) never touches the keyboard directly - it just writes the same config file the daemon reads and wakes it up instantly.

Calibration

—

Recalibrating walks through every LED one at a time - watch the physical keyboard and click whichever key lights up. Starting over replaces the existing mapping, so this is the way to fix a calibration you got wrong.
